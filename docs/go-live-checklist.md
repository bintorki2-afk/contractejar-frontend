## خبر مهم تم التحقق منه

مسار إنشاء العقد للزائر **غير المسجّل** يعتمد فقط على نقاط نهاية **عامة**
(القوائم المنسدلة: المناطق، المدن، مدد العقد، أنواع الدفع، أنواع/استخدامات
الوحدة، صفة المستأجر، الأعمال الورقية). هذه المسارات في السيرفر (Laravel)
مسجّلة بوسيط `api` فقط بدون `auth:sanctum`، فهي متاحة بلا تسجيل دخول أصلًا،
وخطوات المعالج لم تعد تتصل بالسيرفر. **النتيجة: القوائم المنسدلة تعمل بدون
تسجيل دخول — لا حاجة لأي تعديل على السيرفر لتشغيل مسار الطلب.**

## المطلوب منك (بالترتيب)

### 1) متغيّرات البيئة على استضافة الموقع (Vercel مثلًا)

مطلوبة ليصلك الطلب:

- `TELEGRAM_BOT_TOKEN` — توكن البوت من @BotFather (سرّي).
- `TELEGRAM_CHAT_ID` — معرّف المحادثة/القناة التي تستقبل الطلبات.
- `NEXT_PUBLIC_BASE_URL` — رابط السيرفر المباشر مع `/api/v2` بدون شرطة أخيرة.

> بمجرد ضبط توكن تلجرام، تُمرَّر أيضًا **صور الصك/المستندات** التي أرفقها العميل
> إلى تلجرام تلقائيًا بعد نجاح الطلب (عبر `/api/order-attachments`). هذه العملية
> معزولة تمامًا: لو فشلت (حجم كبير/انقطاع)، لا تؤثر على الطلب، وتبقى الصور
> تُستكمل عبر واتساب كالسابق.

مطلوبة للإعلانات والتتبّع (كل الدانه عندك):

- `NEXT_PUBLIC_GTM_ID` — معرّف حاوية Google Tag Manager. عند ضبطه يُحمّل GTM
  ووضع الموافقة وإشعار الكوكيز، وكل طلب يُرسل حدث `generate_lead` تستخدمه كتحويل
  في Google Ads / GA4 / Meta / TikTok / X / Snap من داخل واجهة GTM بلا تعديل كود.
  (التفاصيل في `docs/analytics-and-ads.md`.)
- `NEXT_PUBLIC_SITE_URL` — دومين الموقع النهائي (لِـ sitemap/robots والروابط).
- `NEXT_PUBLIC_LEAD_VALUE` — اختياري: قيمة الطلب بالريال على حدث التحويل.

اختيارية (طبقات موثوقية إضافية لِـ `/api/order`):

- `ORDER_INTAKE_URL` + `ORDER_INTAKE_TOKEN` — تخزين الطلب في قاعدة بياناتك
  (مصدر الحقيقة). النقطة صارت **جاهزة** في الباك-إند — انظر القسم التالي.
- `RESEND_API_KEY` + `ORDER_EMAIL_TO` + `ORDER_EMAIL_FROM` — نسخة احتياطية
  بالإيميل لكل طلب (الثلاثة مطلوبة معًا للتفعيل).

### 2) تخزين الطلب في قاعدة بياناتك (جاهز على فرع الباك-إند)

على فرع `feature/order-intake` في مستودع الباك-إند أضفت نقطة عامة تحفظ كل طلب
كمصدر حقيقة، مستقلًّا عن تلقرام/الإيميل:

- **عام:** `POST /api/v2/orders` — محدود بمعدّل (throttle 20/دقيقة)، منع تكرار
  عبر `order_number`، وسرّ مشترك اختياري (`ORDER_INTAKE_TOKEN`).
- **للوحة:** `GET /api/admin/website-orders` (صلاحية `users.view`).

للتفعيل: ادمج فرع `feature/order-intake` وشغّل الهجرة على السيرفر:

```
php artisan migrate --force
```

ثم في الموقع اضبط `ORDER_INTAKE_URL=https://api.YOUR-DOMAIN.com/api/v2/orders`
(و`ORDER_INTAKE_TOKEN` نفسه في الجهتين لو رغبت بالتحقق). التفاصيل في
`WEBSITE_ORDERS.md` بمستودع الباك-إند و`docs/order-intake-api.md` هنا.

> ملاحظة: سمّيت الجدول/الكيان `website_orders` عمدًا لأن «orders» في اللوحة
> تعني عندكم طلبات العقود (وحدة Contracts). هذه طلبات الموقع الجديدة، مفهوم منفصل.

### 3) الدمج والنشر

بعد مراجعتك ورضاك:

```
# الفرونت-إند
git checkout master && git merge --no-ff rearchitecture && git push origin master
# الباك-إند (لو أردت تفعيل التخزين)
git checkout master && git merge --no-ff feature/order-intake && git push origin master
```

ثم أعِد نشر الموقع، وشغّل `php artisan migrate --force` على السيرفر. (لم أدفع
أي شيء إلى `master` في أي من المستودعين — قرار الدمج قرارك.)

### 4) تشغيل المدونة الذكية تلقائيًا

المهمة المجدولة «نشر مقال المدونة الأسبوعي» جاهزة لكنها غير مربوطة بعد. لتعمل
بالكامل بدونك تحتاج أحد أمرين: ربط المهمة بهذا الكمبيوتر من تطبيق Claude، أو
تزويدي بتوكن GitHub لتنشر المقالات من السحابة. (تفاصيل في `docs/blog-system.md`.)

### 5) الإعلانات

أنشئ حاوية GTM ومعرّفات البكسل (Google Ads / Meta / TikTok / X / Snap) وضعها
داخل GTM، ثم اربط حدث `generate_lead` كتحويل. البنية جاهزة بالكامل من طرف الكود.

### 6) لوحة عرض «طلبات الموقع» (جاهزة على فرع)

في مستودع لوحة التحكّم، على فرع `feature/website-orders-view`، أضفت صفحة تعرض
طلبات الموقع المخزّنة (رقم الطلب، نوع العقد، واتساب، الحالة، التاريخ) على المسار
`/home/website-orders` مع عنصر في القائمة الجانبية. تعمل بعد تفعيل نقطة الباك-إند
(القسم 2). لم أستطع بناءها/تشغيلها هنا (لا توجد تبعيات اللوحة في بيئتي)، لكنها
مستنسخة بدقّة من صفحة «العملاء المحتملين» القائمة ومُتحقَّق من صياغتها — يُنصح
ببنائها مرّة عند الربط.

## اختبار سريع بعد النشر

1. افتح صفحة إنشاء العقد بدون تسجيل دخول — تظهر القوائم المنسدلة والتنقّل يعمل.
2. أكمل حتى خطوة الإرسال، أدخِل رقم واتساب صحيح، واضغط إرسال.
3. تحقّق من وصول الطلب إلى تلجرام (وإن فعّلت الإيميل/التخزين، تحقّق منهما، ومن
   وصول صور الصك إلى تلجرام إذا أرفق العميل صورًا).
4. تحقّق من `/{الدومين}/sitemap.xml` و`/{الدومين}/robots.txt` وأن `/blog` يعمل.
